# Deni Portfolio — Vite + React + TypeScript

Template portfolio dashboard dengan layout sidebar, statistik, dotted background, sections, dan responsive mobile.

## Jalankan project

```bash
npm install
npm run dev
```

Buka URL yang ditampilkan Vite, biasanya `http://localhost:5173`.

## Build production

```bash
npm run build
npm run preview
```

## Kustomisasi

- Edit data profil dan isi section di `src/App.tsx`.
- Edit tampilan di `src/styles.css`.
- Ganti foto placeholder di `public/profile-placeholder.svg`.
- Tambahkan file CV dengan nama `public/cv.pdf`.
- Ganti link Instagram, GitHub, project, dan kontak sesuai data kamu.

Catatan: Ini adalah implementasi ulang berdasarkan referensi tampilan, bukan source code asli website referensi.
